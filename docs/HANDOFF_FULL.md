## ۴. چه چیزی مانده

### ۴.۱ قفل‌شده روی تصمیم مالک (بدون این‌ها Phase 2 جلو نمی‌رود)

| مورد | چرا لازم است |
| --- | --- |
| میزبان ایران (هزینه + احراز هویت) | runtime واقعی، دامنه، SSL، پشتیبان‌گیری |
| قیمت اشتراک، درصد کمیسیون، سیاست استرداد | در کد و متن نباید حدس زده شود |
| متن حقوقی، حریم خصوصی، شرایط واگذاری | صفحات عمومی و قرارداد |
| فایل و مجوز فونت Kalameh | هویت برند |
| لوگوی نهایی + ویدئوی برند | جایگاه Hero برای ویدئو آماده است |
| دادهٔ برندهای واقعی (حداقل سه برند پایلوت) | جایگزینی دادهٔ ساختگی |

### ۴.۲ کار فنی Phase 2 (به ترتیب وابستگی)

1. **دیتابیس قابل حمل**: Docker/Postgres/WSL روی این سیستم نیست ⇒ `embedded-postgres` (npm) یا نصب winget.
2. **طرح داده**: تبدیل `DATABASE_SCHEMA.md` به `prisma/schema.prisma` + مهاجرت اولیه.
3. **احراز هویت و RBAC**: نقش‌ها `Applicant`, `Franchisor`, `VerificationOfficer`, `Admin`, `SuperAdmin`؛ احراز هویت دو طرف و لاگ ممیزی تغییرناپذیر.
4. **API**: تبدیل `API_SPECIFICATION.md` به Route Handlers با اعتبارسنجی سرور و کنترل دسترسی در هر درخواست (نه فقط UI).
5. **دادهٔ اولیه**: seed از `lib/data.ts` برای شش فرصت + صنایع از دیتابیس.
6. **پرداخت زرین‌پال**: تأیید سمت سرور، `idempotency key`، تطبیق مبلغ با فاکتور داخلی، جلوگیری از ثبت تکراری.
7. **گفت‌وگو**: فقط پس از تأیید تیم، حضور کارشناس با دسترسی محدود، ثبت مشاهده در ممیزی.
8. **تست**: واحد برای قواعد تطبیق و RBAC، قراردادی برای API، E2E برای مسیر پرونده.

### ۴.۳ بهبودهای کوچک باقی‌مانده

- صفحهٔ فرصت‌ها: `Notice` در فایل ایمپورت شده ولی استفاده نمی‌شود (تمیزکاری).
- `.badge` تنها گوشهٔ ۲px باقی‌مانده در سیستم است؛ اگر «مربع کامل» خواستی، صفر شود.
- گام‌های فرم در `join` هنوز حالت اعتبارسنجی ندارد (فقط نمایشی).
- دادهٔ ساختگی باید هنگام اتصال به دیتابیس حذف شود تا با دادهٔ واقعی قاطی نشود.

## ۵. قفل‌های محصول (بدون اجازهٔ مالک تغییر نمی‌کنند)

1. بازار فقط ایران؛ زبان فقط فارسی و کاملاً RTL.
2. مدل Managed: پلتفرم واسطهٔ بررسی‌شده است، نه تابلوی آگهی.
3. ساخت برند رسمی و انتشار فرصت فقط با Admin / Super Admin.
4. احراز هویت هر دو طرف پیش از هر تماس.

9. بدون آمار، برند یا نظر ساختگی به‌عنوان واقعیت.
10. ظاهر لوکس و مینیمال؛ ترکیب زرد/مشکی به‌عنوان هویت ممنوع.

```powershell
# پیش‌نمایش محلی
cd franchise-plus-platform
$env:NEXT_PUBLIC_BASE_PATH="/franchise-plus"; npm run build
# کپی out/* به .localserve/franchise-plus و سپس:
python -m http.server 4174 --directory .localserve
```

```powershell
# انتشار روی GitHub Pages
cd franchise-plus-platform
$env:NEXT_PUBLIC_BASE_PATH="/franchise-plus"; npm run build
$pub = "..\.publish-fp"
Get-ChildItem $pub -Force | Where-Object { $_.Name -ne '.git' } | Remove-Item -Recurse -Force
Copy-Item "out\*" $pub -Recurse -Force
New-Item -ItemType File -Path "$pub\.nojekyll" -Force
cd $pub
git add -A; git commit -m "Deploy"; git push --force origin gh-pages
```

نکته: در PowerShell، `git push` خروجی خود را روی stderr می‌دهد و به‌شکل `NativeCommandError` دیده می‌شود؛ خطا نیست.
