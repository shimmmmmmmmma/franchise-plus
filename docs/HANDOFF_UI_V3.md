## کارهای این مرحله (پس از v3)

- **منوی موبایل ساخته شد** (`components/shell.tsx`): دکمهٔ `.menu-toggle` زیر ۷۶۰px،
  کشوی تمام‌صفحه `.drawer` با شماره‌گذاری فارسی، بستن با Escape، قفل اسکرول، بستن خودکار
  با تغییر مسیر، و `tabIndex` مدیریت‌شده برای لینک‌های بسته.
- **انیمیشن ظاهر شدن مقاوم شد**: محتوا پیش‌فرض دیده می‌شود؛ فقط وقتی اسکریپت اجرا شود
  (کلاس `js` روی `<html>` از یک اسکریپت کوچک در `layout.tsx`) پنهان می‌شود. علاوه بر آن،
  اگر عنصر همان لحظه در دید باشد فوراً نمایش داده می‌شود و یک تایمر ۲٬۵ ثانیه‌ای
  شبکهٔ اطمینان است. دیگر «صفحهٔ خالی تا اجرای JS» نداریم.
- **سطوح محصول هم‌زبان شدند**:
  - `.card-flat` → کادر مربع با خط مو (بدون شعاع و بدون سایه).
  - `.kpi` → فقط خط بالایی، عدد با Estedad.
  - `.next-action` → نوار برنزی سمت شروع به‌جای گرادیان.
  - `.panel__nav-item` → ردیف‌های فهرستی با خط جداکننده و نشانگر برنزی، بدون بلوک سرمه‌ای.
  - `.msg` در چت → «ترانسکریپت»: بدون حباب، خط بالایی برای هر پیام، نوار عمودی برای
    پیام خودم، یادداشت کارشناس با نوار برنزی.
  - `.notice` → بدون قاب، با نوار عمودی و خط مو.
  - `.badge` → قاب ۲px به‌جای پیل.
  - `.tl-dot` و مونوگرام برند → مربع مویی به‌جای دایره/کارت گرد.
  - «فرصت‌های مشابه» در صفحهٔ جزئیات هم به `.ledger` تبدیل شد.
- **رفع سرریز افقی در موبایل/تبلت**: `.panel > * { min-width: 0 }`، ناوبری پنل در موبایل
  به‌صورت ردیف قابل‌شکستن (نه اسکرول افقی)، و `.chat__compose` قابل‌شکستن.

## یادداشت‌های فنی

- بیلد: `NEXT_PUBLIC_BASE_PATH=/franchise-plus npm run build` → `out/`.
- انتشار: کپی `out/*` به `.publish-fp/` + `.nojekyll` + `git push --force origin gh-pages`.
- پیش‌نمایش لوکال: `python -m http.server 4174 --directory .localserve` (مسیر شامل basePath).
- **هشدار دربارهٔ اسکرین‌شات هدلس**: در حالت `--headless` تصویر صفحه‌های RTL در عرض‌های
  کوچک جابه‌جا/بریده می‌شود؛ برای بازبینی موبایل از پنل مرورگر استفاده کن، نه از هدلس.
